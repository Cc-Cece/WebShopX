使用教程

以下是常用流程的简版说明，后续可继续补充为完整文档。

注册与登录

新玩家：先点“获取绑定码”，回游戏执行 /webshopx bind <code>（或 /ws bind <code>），再回网页设置密码完成注册。

老玩家：直接使用 UUID 或 MC 名 + 密码登录。

购买与退款

下单前会二次确认；若服务器开启冷静期，订单会延迟发放并可在冷静期内退款。

玩家市场

上架在游戏内执行命令，价格与备注在网页内管理。购买玩家也走订单流程，可在订单页查看状态。

资产说明

建议下单或交易前先点击“刷新余额”，确保显示与数据库当前余额一致。

兑换说明

若提示方向不可兑换，说明管理员在当前服务器配置中关闭了该兑换方向。

下单提示

订单创建后会进入发货队列。若角色离线，物品会在下次上线时自动投递。

冷静期说明

若服务器开启冷静期，下单后会延迟发放，并允许在冷静期内退款。

团购券商品

购买后会生成团购兑换码，请通过你自己的渠道提供给管理员核销。核销后该兑换码失效。

操作日志

用于快速排查接口调用与会话状态，最新日志始终在顶部。

排障建议

若遇到异常，请优先查看最近三条日志并与服务器控制台时间对照，定位会更快。
