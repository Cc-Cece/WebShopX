使用教程

以下是常用流程的简版说明，后续可继续补充为完整文档。

密码设置与登录

第一步：在游戏内执行 /webshopx password <新密码>（或 /ws password <新密码>）设置网页登录密码。

第二步：回到网页，使用你的 Minecraft 用户名和该密码登录。

购买与退款

下单前会二次确认；若服务器开启冷静期，订单会延迟发放并可在冷静期内退款。

玩家市场

上架可在游戏内使用 GUI 完成；价格与备注在网页内管理。供货箱模式支持手动刷新与售罄后自动补货。

资产说明

建议下单或交易前先点击“刷新余额”，确保显示与数据库当前余额一致。

兑换说明

若提示方向不可兑换，说明管理员在当前服务器配置中关闭了该兑换方向。

下单提示

订单创建后会进入发货队列。若角色离线，物品会在下次上线时自动投递。

冷静期说明

若服务器开启冷静期，下单后会延迟发放，并允许在冷静期内退款。

团购券商品

购买后会生成团购兑换码，请通过你自己的渠道提供给管理员核销。核销后该兑换码失效。

操作日志

排障建议

若遇到异常，请查看日志，必要时可带上日志向管理员或开发者求助。
