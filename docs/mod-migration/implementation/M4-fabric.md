# M4：Fabric 全功能发行线

## 目标

在 Fabric 1.18.2 至冻结最新版本的全部承诺发行单元实现插件版业务等价。

## 版本策略

先完成 1.18.2、1.20.1 和 modern 锚点；再按 M1 ADR 将目标范围展开为精确产物或验证过的兼容区间。不能用一个锚点自动宣称中间所有版本支持。

## 平台实现

- Loader 生命周期、配置目录、命令/补全、权限和本地化消息；
- 正确线程调度、在线玩家目录、加入/退出与关闭事件；
- 原版/Mod 物品 codec、在线背包原子操作和安全离线数据访问；
- 标准容器 GUI 或完整的命令/Web 替代路径；
- capability、健康、日志、遥测和更新提示；
- 经济/权限/支付 Provider 发现与安全降级；
- 内置 HTTP、external 和 Relay 三种部署模式；
- SQLite/MySQL/MariaDB、Redis 与维护任务。

## 业务验收路径

- 首次启动 → 玩家绑定/登录 → 钱包 → 官方商品 → 下单 → 发货/邮箱/领取；
- 市场出售/收购/拍卖/退款/补货；
- 充值、支付回调、兑换、会员、通知；
- 管理后台用户、商品、订单、经济、市场、语言、主题、审计和系统配置；
- 在线/离线、背包不足、重复请求、重启和 Relay 断线恢复；
- Mod 物品与嵌套容器 round-trip。

## 验收

- [08-acceptance.md](../08-acceptance.md) 对所有 Fabric 承诺单元通过；
- 无 WebShopX 客户端附属 Mod 时业务完整；
- Paper 基线同时通过；
- 每个产物在干净 dedicated server 启动并验证真实 Mod 物品；
- 不支持的第三方 Provider 只影响相应能力；
- 支持矩阵准确，不使用未验证的“+”。

## 回退

Fabric adapter 可从构建矩阵移除而不影响 Paper/core；任何共享数据变化必须保持 Paper/其他 Loader 可读。
