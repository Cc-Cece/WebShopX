# M5：Forge 1.18.2–1.20.1 全功能发行线

## 目标

为 Forge 1.18.2 至 1.20.1 建立正式兼容线，功能和数据语义与 Paper/Fabric 一致。

## 任务重点

- 根据精确 Forge/Java/映射矩阵建立版本族，处理 API 差异而不污染 core；
- 实现生命周期、事件总线、命令、权限、调度和 dedicated server 入口；
- 使用 Forge 注册表/物品能力实现无损 codec 与缺失 Mod 拒绝；
- 实现在线和离线玩家背包安全操作，验证玩家登录竞态；
- 对接标准容器 GUI/命令/Web、Provider SPI、HTTP/Relay 和集群；
- 验证与常见服务端优化/权限环境共存，具体候选由 M0/M8 ADR 决定；
- 处理 Java 库在 legacy 版本的兼容下限，不能把不兼容依赖塞入 JAR。

## 版本覆盖

至少真实验证 1.18.2 与 1.20.1。若产品承诺包含中间每个小版本，必须各自产物/启动验证；若采用兼容区间，ADR 必须给出 Loader API 与二进制兼容证据。

## 验收

- 完整执行功能矩阵、原生物品 fixture、离线发货和故障恢复；
- 同一业务数据库与其他节点并存时路由正确；
- Forge 事件不重复注册，停服任务/HTTP/连接池正确关闭；
- 没有将 NeoForge API 或元数据误打包；
- Paper、Fabric 既有门禁不回归；
- Forge 是正式目标，不得因维护成本单方面改为可选。

## 回退

Forge 模块和 CI job 独立；共享 core/schema 变化必须能由其他平台继续运行。发行线是否停止只能由项目所有者决定。
