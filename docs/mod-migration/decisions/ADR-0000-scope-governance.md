# ADR-0000：项目范围与治理

- 状态：Proposed，等待项目所有者审核本计划后改为 Accepted
- 日期：2026-08-22
- 决策者：项目所有者
- 关联：整个 Mod 重构

## 背景

现有 WebShopX 是 Paper/Bukkit 插件。目标是长期同时维护插件与三个 Mod Loader，并允许独立程序员/审核者只依赖持久文件协作。

## 决定

- Fabric 目标为 1.18.2 至冻结最新版本；
- Forge 目标为 1.18.2 至 1.20.1；
- NeoForge 目标为 1.20.1 至冻结最新版本；
- 下一个正式 Mod Release 以插件版业务功能等价为门槛；
- 核心为服务端 Mod，客户端增强默认可选；
- 使用共享业务核心和平台 adapter；数据库业务实体可共享，物品按兼容域隔离；
- 每个 Mxx 一个正式审核，修复后只闭环原问题；全部完成后再做一次最终审核；
- Agent 可决定不涉及 `main` 的正常实施、审核和 `mod-integration` 流程；任何涉及 `main` 的决定与操作只属于项目所有者。

## 后果

维护成本随 Loader × 版本族 × 验证环境增长。计划不能用“可编译”替代功能、数据和真实服务器验收。实现细节保持自由，但范围缩减、破坏兼容或改变 main 权限必须再次由项目所有者决定。

## 接受方式

项目所有者批准本计划后，由文档 PR 或后续只含文档的提交把状态改为 `Accepted` 并记录批准位置；Agent 不得自行把 Proposed 改为 Accepted。
